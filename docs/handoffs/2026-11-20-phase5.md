## The shape of it, for Phase 6 and after

- **Lanes carry frequency.** A band in Env or Track has lanes whatever its gain mode.
  - `Chain::laneFrequencies` holds, per band and lane, the modulator's output (log2 Hz) and the g
    the filter runs on this step.
  - The band's filter is one control step behind its lane; `Chain::appliedFrequencyHz` says where
    it is.
  - A lane at the band's own frequency (`own`) takes the band's own g: Phase 2's bits.
- **`Chain::frequencyHz (band, channel)`** is the lane's frequency now. `bandMeter` reports the
  link lane's frequency, and its tracker's confidence. These are what Phase 6's curve and its
  horizontal brackets read.
- **Track runs in its own pass**, `Chain::track`, before the bands: the bands of one key source,
  lane by lane, in `runTrackerGroup` (`dsp/Tracker.h`). At each grid point,
  `Chain::seedTrackers` places the released trackers, from `dsp/SeedBank.h`.
- **A sample whose mix is the identity is never written**, on any path, whether g moves or not.
- **`Band::coefficientsWithG`** is the general per-lane form: its own g, an offset and a gain scale.
  `runBandPerLane` uses it for any lane off the band's own frequency, and for confidence scaling.
- **`core::Dispatch`** reads all 35 values of a band.

## Things that will bite

- **Heredocs in Git Bash** broke twice more this session, on quotes inside `<<'EOF'`. Write patch
  files with the Write tool, then apply them with a script from the scratchpad. A small exact
  replacer (`@@@OLD` / `@@@NEW` / `@@@END` blocks) did all of this phase's edits. On Windows Python
  prints file names in cp1252, and the PRD's `ū` makes `print` fail *after* the write: check the
  file, not the exit code.
- **doctest's `-tc`**: give one `-tc` with comma-separated patterns, each free of commas (`?` in
  place of a comma). A second `-tc` replaces the first.
- **A `const char*` ternary inside `INFO`/`MESSAGE`** prints as `1`: wrap it in `std::string`.
- **A configure after adding a test file** failed once again ("Configuring incomplete"); the second
  run passed.
- **MSVC and aliasing**: a helper that takes the work buffer and the coefficients by pointer made
  MSVC reload the coefficients after every store (+21 % on the moving path). Copy them into locals
  inside the loop (`Chain.cpp`, `tickOrAdvance`).
- **A test of a tracker must say where it starts and what it reads.** A released tracker's
  estimate wanders on noise, at full speed, and is seeded at each grid point, so a band at rest is
  not a tracker at rest.
- **The farm** was not used this session.
