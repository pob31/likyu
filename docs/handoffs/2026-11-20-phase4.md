## The shape of it, for Phase 5

- **The chain owns the lookahead.** `Chain::process (audio, key)` reads the key of a stretch,
  then delays that stretch in place (`line<Sample>().process`), then runs the bands; the shim
  passes `key.self = audio` and the whole host block.
  - Anything Phase 5 adds that reads the key must read it in that first part of the stretch, with
    the detectors: the trackers, the seeding bank, Env's follower.
  - The line is a bit-exact copy in the host's type; flush-to-zero does not touch it.
- **The gain mode in effect** is `Band::Shape::gmode`, and `hasOffset()` means Dynamic or
  Transient. The frequency mode is the other axis and goes in the shape the same way, if it has
  switches that must go through the identity.
- **Per-lane state lives in the chain**, `Chain::envelopes` beside `offsets`. The per-sample loop
  lives in the class that owns the computation (`TransientComputer::run`), called once per
  stretch, because MSVC does not reliably inline a per-sample call from `Chain`. Env's follower
  and the trackers (on the mean of the key's channels when linked) fit the same pattern.
- **Rule A is untouched:** an offset of exactly 0 takes the Phase 2 coefficients. Transient
  returns to exactly 0 through the same 0.0001 dB.
- **`core::Dispatch`** reads four more values (`tatk`, `tsus`, `ttime`, `tfloor`); Phase 5's
  frequency values come next.
- **The temporary parameters** (`tmp_listen` until Phase 6, the four `tmp_t*` until the listening
  pass) are outside the table, the state and the dispatch. The processor's first test counts
  284 + 1 + 4.
- **The bench** has `--scenario transient` and `--lookahead` on every scenario. The budget's own
  case needs Track.

## Things that will bite

- **A heredoc in Git Bash** broke again on a quote. Write the patch script to the scratchpad and
  run it from there, as the Phase 2 and 3 notes said. Python's `write_text` on Windows writes
  CRLF: use `write_bytes`, or `newline="\n"`.
- **doctest's `-tc` splits on commas.** A test name with a comma needs a wildcard pattern that
  leaves it out.
- **A configure right after adding a source file** failed once ("Configuring incomplete") and
  passed when run again; the build in between used the stale project, without the new file.
  Check that the new file's tests ran before trusting a run.
- **A steady sine has no attack and no sustain:** its Transient offset is 0. A Transient test
  needs a level that moves: the swung sine of `MovementTests.cpp`, or bursts.
- **The Range clamp can hide a difference.** The temporary-constants test needed Range 30 dB to
  see a slow attack four times longer.
- **A push cancels the CI run in progress** (`cancel-in-progress` in `ci.yml`). Wait for a run to
  finish before pushing the next commit, or its result is lost.
- **`-Wfloat-equal`** (GCC and Clang): no warning on these commits, but an exact comparison outside
  a doctest macro still goes through `dsp::exactlyEqual`. Grep CI's log for `warning:` outside
  `ThirdParty/` after each push.
- **The farm** was not used this session.
