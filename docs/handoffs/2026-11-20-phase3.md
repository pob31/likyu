## The shape of it, for Phase 4

- **`lib/dsp/dsp/Chain.h` reads a `Key`** beside the audio: the main input undelayed and the
  sidechain. In the plugin the key is a copy taken before the lookahead; Phase 4 moves the
  lookahead into the chain (devplan), and can then drop that copy.
  - Keep the invariant that the old overload relies on: every key sample of a stretch is read
    before any audio of it is written.
  - The current `Lookahead` only moves samples. Flush-to-zero does not touch it, so it can run
    inside the chain's scope.
- **Lanes:** a band's gain comes from one lane per group of channels that share a gain (Sidechain:
  one; Linked: the link plus one per channel left out; Unlinked: one per channel). Each lane has
  one offset in double, smoothed per sample. **Transient produces an offset too**: it plugs in
  where `detect()` turns a lane's power into a target, a different source for the same offset.
  Its four envelopes run on the lane's level.
- **Rule A, the exact bypass under per-sample offsets** (`Chain::runBand`, `runBandWithOffsets`):
  - a sample whose offset is exactly 0 takes the Phase 2 coefficients;
  - an identity is skipped only in a constant step;
  - only the samples a stage touched are written back (a 16-bit mask per channel).

  Anything Phase 4 adds that changes the signal marks what it touched.
- **The shape** (`Band::Shape`) carries every discrete choice that goes through the identity:
  - its `operator==` compares only what matters for the band, so that an irrelevant change costs
    no fade;
  - Transient's own switches belong there;
  - the chain rebuilds a band's lanes when its shape revision moves, and clears its detectors when
    its detector revision moves.
- **`Band::detectorCoefficients()` is made on demand,** once per step, on the first call after the
  grid point. Call it only after `beginStep()`.
- **`core::Dispatch`** reads 13 more of a band's values since this phase; Transient's four are next.
  `bandSettingsFrom` and `BandSettings` grow, nothing else.
- **The temporary Listen parameter** (`tmp_listen`, `dsp::temporaryListenSpec()`) is outside the
  table, the state and the dispatch. Phase 6 removes it.

## Things that will bite

- **A heredoc in Git Bash** broke twice on the way, on a script with quotes in it. Write the patch
  script to the scratchpad and run it from there, as the Phase 2 note said.
- **MSVC's inlining is not to be relied on.** A per-sample call into the band stopped being inlined
  when the band grew, and cost 40 % on the static path with every ramp running. Fill per-sample
  arrays inside the class whose function is called (`Band::coefficientsFor`).
- **`-Wfloat-equal` is on in CI's GCC and Clang,** not in MSVC's view. An exact comparison outside
  a doctest macro goes through `dsp::exactlyEqual`. Three in this phase's tests showed in CI's logs
  on the 3b commit (`8e8d611`) and were fixed in the 3d one. CI does not fail on a warning: grep
  its log for `warning:` outside `ThirdParty/` after each push.
- **A detector's first sample after silence reads −120 dB,** exactly: v1² − v2·hp is 0 there. A
  test of a Below band must give the start time to return.
- **A test that runs a processor twice sees the first run's tail.** The link exclusion test needed
  a second of quiet first. An offset releasing from the last buffer shows on every channel as soon
  as the shape fades.
- **doctest's `INFO` prints only on failure;** a figure the bench note needs is a `MESSAGE`.
- **The farm** was not used this session.
