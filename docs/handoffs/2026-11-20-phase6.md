## Testing on the three machines

**The builds.** Each CI run on `main` keeps the Release plugins as artifacts:
`likyu-windows-unsigned` (VST3, both LV2), `likyu-macos-unsigned` (VST3, AU, LV2),
`likyu-linux-unsigned` (VST3, both LV2). `gh run download <run> -n likyu-macos-unsigned`, or the
run's page. They are unsigned: on the Mac, `xattr -dr com.apple.quarantine` on each bundle before a
host sees it. `scripts/farm-check.sh` builds and checks on the farm instead.

**What only a host can tell**, in roughly the order it is worth looking:

1. The editor opens, resizes, and draws at the host's scale (Samplitude's scaled display drew the
   probe correctly in Phase 1).
2. Live: the parameters appear in its list once a node or a control has moved (Phase 1, finding 6).
3. Nodes: the centre, each arm, the wheel for Q, double click for 0 dB, Shift for a fine drag; a
   host that takes the wheel or Shift for itself.
4. Touch, on Windows with the touch screen: two nodes at once, two fingers on one node for Q. Phase 1
   found that every Windows host passes several fingers once the editor asks; Samplitude passed one.
5. The channel cells on a 5.1 track in REAPER: a low cut that spares the LFE, a low-pass on the LFE
   alone; the session saved and reopened.
6. Listen: a long press, heard until released. The analyser with a sidechain routed and not; the
   key badge reading `SC?` when the sidechain is not there.
7. pluginval and auval were run in CI only on the Release builds of each commit; nothing more is
   needed there.

**The listening material** the devplan asks for: drums, plucked strings, speech with sibilance, a
full mix keyed by a voice; a de-esser that follows two voices, a boost that follows a bass line, an
envelope filter on a guitar. Notes go in `docs/bench/`.

## The shape of it, for Phase 7 and after

- **`src/editor/`** is an INTERFACE target, `likyu::editor`. What it says is in five headers with
  no JUCE (`Presentation.h`, `CurveGeometry.h`, `QGestures.h`, `ResponseCurve.h`, and `Spectrum.h`),
  tested headless; the components paint what they return.
- **`EditorRoot` knows a `Host` of functions and no shim**: the CLAP shim fills the same struct.
  The four temporary constants are reached past the table's indices (`EditorHost.h`); they go with
  them.
- **The foot's grid** is `presentation::footPlaceOf`: a control has one place whatever the modes.
  A test holds that no two controls shown together share one.
- **A band's channels** are a mask per band in the chain (`Chain::setBandChannels`), lists with
  their layout in the state (`core/BandChannels.h`, `band_out`), and the processor's
  `setBandChannelsLeftOut` for the editor.
- **Listen** is `LikyuProcessor::setListen`, an atomic read once per block; nothing else sets it.
- **The analyser's tap** (`core/AnalyserTap.h`) writes only while the editor shows it.
- **Go.dot's warning** (a Sidechain band in Go.dot is keyed by silence until Phase 9) is in
  `presentation::badgeOf`, behind `hostFeedsSilence`, and nothing passes it true yet: Phase 8 is
  where the editor learns it is in Go.dot.

## Things that will bite

- **Inline scripts in Git Bash** broke again on quotes. Write the script to the scratchpad with the
  Write tool and run it with `python`; every edit of the phase went that way.
- **A push while CI runs cancels the run's Windows job** (the newest run takes the concurrency
  group). Wait for the run to end before pushing the next commit, or read the cancelled job as
  untested.
- **`LIKYU_SNAPSHOT_DIR`** makes `likyu_tests` write the editor's pictures: the default, one per
  mode, the ghost, the times panel, the analyser, and 48 frames of random values. That is how the
  editor was looked at all phase.
- **Mouse events in tests are built by hand** (`eventAt` in `EditorTests.cpp`). The curve's pointer
  calls (`pointerDown`, `pointerMoved`, `pointerUp`) take a kind and an index, so a test can be
  a touch.
- **A press on a node's edge**: the geometry's sizes are not whole numbers at every plot height.
  The test presses half a pixel inside.
- **The window's minimum is 1100 wide**: the foot's four blocks and the channels need it.
- **Samplitude remembers a plugin's generic view.** After the editor-less builds of Phases 0 to 5 it
  opened the new editor as its own sliders. Seen by the author on 2026-11-21 and cured in the host:
  the plug-in folder removed from Samplitude's list, a scan, the folder back, a scan again. Nothing
  in the plugin forces it; the plugin reports its editor to every host.
- **Seen in a host on 2026-11-21**, since this note was first written: dropdowns lost a pick while
  audio ran (fixed, `a7c8989`); Listen now latches (the author); in Transient, Range is a two-sided
  dial (the author, `1de412b`).
