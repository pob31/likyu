## The shape of it, for Phase 3

- **`lib/dsp/dsp/Chain.h`** is the audio path.
  - It runs in **control steps of 16 samples** on a grid counted from `prepare` and across calls.
    `setBand` and `setChain` are called on the audio thread between blocks, and land at the next
    grid point. That is what makes the output bit-exact whatever the block size; keep anything
    new on the grid.
  - A step that alters nothing **does not write the host's buffer**: that is the exact bypass.
    Anything Phase 3 adds that changes the signal must say so (`runBand` returns true).
- **`lib/dsp/dsp/Band.h`** holds one band's control state.
  - The **dynamic offset** of Phase 3 enters as the gain in dB per sample.
    `effectiveGainDb` (`Gain.h`) already clamps static + offset. `coefficientsAt` computes A from
    the dB per sample when the gain moves; when it moves every sample (an offset), the constant
    path will be rare, which is the cost to watch.
  - The **return to zero** must give exactly 0 dB, so that the step after it is constant and an
    identity again.
- **Switches go through the identity:** the mix crossfades to (1, 0, 0) along a smoothstep, 10 ms
  each way. The gain mode, frequency mode and key switches of Phases 3 to 5 can use the same path
  (`Band::Shape`).
- **`likyu::core::Dispatch`** reads all 35 values of a band. It hands the chain the band when any
  of them moved, but only six reach `BandSettings` today. Phase 3 extends `BandSettings` and
  `bandSettingsFrom`, nothing else.
- **State chunk version 1** (`core/State.h`) is flat by ID and keeps unknown fields. The link list
  of Phase 3 can be added to it without a version bump: nothing is shipped before the freeze.
- **The sidechain** is still not read: `LikyuProcessor::process` passes only the main channels to
  the chain.

## Things that will bite

- **`-Wfloat-equal` is on.** An exact comparison that is meant goes through
  `dsp::exactlyEqual`. Dispatch compares parameter values as bits (`memcmp`).
- **A cached result must record everything it was made from.** The band's constant coefficients
  forgot the band's type once, and a finished fade-in sent the band back to its old type. The
  switch test with its hard-switch control is what caught it; keep such a control beside any new
  click test.
- **doctest prints a bare `const char*` as an address or a number in `INFO`** (it printed "1" and
  "11"). Wrap it in `std::string`.
- **A host range is in float.** 0.1 as a float is a little above 0.1: a mapping that divides by
  the double bound reads the range's own end back as 2.5e-9, and auval warns (32 times, CI,
  2026-11-20). The shim maps between the float bounds JUCE passes; the processor test sets and
  reads back both ends of every parameter.
- **MSVC's `long double` is `double`.** The double column of `likyu_bench precision` only means
  something on GCC or Clang on x86-64: CI's Linux job prints it.
- **Python patches through a Git Bash heredoc** broke again (a quote in the text). Write the
  script to the scratchpad and run it. On Windows, Python's `write_text` writes CRLF: use bytes.
- **`likyu_bench time`'s worst block is Windows' scheduling,** not the DSP, on an ordinary thread.
- **The farm did not answer** over SSH on 2026-11-20.
